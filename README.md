# Teekaart.ee

Neutraalne otsustusleht Eesti ettevõtte omanikule, kes ei tea veel, kas järgmine õige samm on digiteekaart, digitaliseerimine, automatiseerimine või väiksem praktiline töö.

Fookus:

- omaniku keeles esimene suunav vastus;
- 3-5 võimaliku tee eristamine;
- lead'i kogumine enne täpsemat käsitsi analüüsi;
- suunamine õigele järgmisele maandumislehele.

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Environment

- `PUBLIC_GA_MEASUREMENT_ID` - GA4 measurement ID
- `PUBLIC_SITE_LEAD_WEBHOOK_URL` - n8n/Supabase/Resend lead webhook
